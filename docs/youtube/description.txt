GitHub project and installer: https://github.com/PrajeetShrestha/voice-cli

Generate local MP3 voiceovers on your Mac with Voice Studio. This walkthrough shows installation, the compact Web UI, Siri voice selection, speech speed, automatic regeneration, and how agents such as Codex or Claude can generate narration through the local helper or HTTP API.

The narration in this video was generated with Voice Studio itself using Nora.

INSTALL
curl -fsSL https://raw.githubusercontent.com/PrajeetShrestha/voice-cli/v0.1.0/install.sh | /bin/sh

START THE WEB UI
~/.local/bin/voice-studio

Requirements: macOS 13+, Swift 5.9+ through Xcode or Apple Command Line Tools, an installed natural Siri voice, and ffmpeg with libmp3lame. The installer can install ffmpeg through an existing Homebrew setup. It does not install Homebrew, Apple tools, or voice assets.
